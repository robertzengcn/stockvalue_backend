<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| FastAPI -> Redis (arq pool) | Job enqueuing crosses process boundary |
| Worker -> PostgreSQL | State updates cross process boundary |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-05 | T | State transitions | mitigate | SELECT FOR UPDATE prevents concurrent modification; validate_transition rejects invalid transitions before DB write |
| T-05-06 | D | Worker job queue | accept | arq max_tries and timeout prevent single job from consuming all resources; configurable max_concurrent_tasks |
| T-05-07 | T | Job arguments | mitigate | arq serializes as msgpack; job args are task_id strings (UUID), not user input |
| T-05-08 | I | Reaper cron | accept | Reaper reads from trusted DB source; no user-controlled input affects reaper logic |
</threat_model>
