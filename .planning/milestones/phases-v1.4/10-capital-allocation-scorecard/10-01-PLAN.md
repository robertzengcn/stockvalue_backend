    **Create `stockvaluefinder/stockvaluefinder/services/capex_service.py`** with 7 pure functions.

    All functions are stateless pure functions following the `roic_service.py` pattern. Import `capital_allocation_config` from config.py for thresholds.

    **1. `calculate_buyback_yield(repurchase_amount: float | None, market_cap: float | None) -> float | None`**
    - Per D-02: buyback_yield = annual_repurchase_amount / market_cap
    - Return None if repurchase_amount is None or market_cap is None or market_cap == 0
    - Return round(yield_value, 6)

    **2. `grade_buyback_yield(buyback_yield: float | None) -> CapitalAllocationGrade`**
    - Per research assumption A3: > 2% = A, 1-2% = B, 0.5-1% = C, < 0.5% = D, None = D
    - Read thresholds from capital_allocation_config.BUYBACK_YIELD_GRADE_A/B/C

    **3. `classify_dividend_stability(dpu_values: list[float], years: list[int]) -> dict[str, Any]`**
    - Per D-04: Reuse analyze_roic_trend() pattern from roic_service.py
    - Filter out None, NaN, and zero DPU values
    - Require at least MIN_DPU_DATA_POINTS (3) valid data points
    - Use scipy.stats.linregress with ordinal x-axis positions
    - Slope > DPU_TREND_THRESHOLD (0.05) = GROWTH, slope < -0.05 = DECLINE, between = STABLE
    - Return dict: {classification: DividendTrend, slope, p_value, data_points}

    **4. `grade_dividend_stability(classification: DividendTrend) -> CapitalAllocationGrade`**
    - GROWTH = A, STABLE = B, INSUFFICIENT_DATA = C (neutral), DECLINE = D

    **5. `detect_blind_expansion(roic: float | None, wacc: float, capex_current: float | None, capex_previous: float | None) -> dict[str, Any]`**
    - Per D-05: Alert when ROIC < WACC AND YoY CapEx growth > 20%
    - Handle None inputs: return alert=False with reason="insufficient_data" if roic is None
    - Handle capex_previous == 0: return alert=False with reason="no_prior_capex"
    - Use abs() on CapEx values (cash flow outflow is negative) before computing growth
    - capex_growth = (abs(capex_current) - abs(capex_previous)) / abs(capex_previous)
    - Return dict: {alert: bool, roic_wacc_spread, capex_yoy_growth, capex_current, capex_previous, reason: str | None}

    **6. `grade_expansion_discipline(blind_expansion: dict[str, Any]) -> CapitalAllocationGrade`**
    - No alert = A
    - Alert + capex_growth <= 50% = C
    - Alert + capex_growth > 50% = D
    - Insufficient data = C (neutral, per research assumption A4)

    **7. `calculate_capital_allocation_score(buyback_grade: CapitalAllocationGrade | None, dividend_grade: CapitalAllocationGrade, expansion_grade: CapitalAllocationGrade) -> tuple[CapitalAllocationGrade, dict[str, float]]`**
    - Per D-07/D-08: Equal weights (1/3 each), A=4, B=3, C=2, D=1
    - If buyback_grade is None (no buyback data): reweight dividend and expansion to 0.5/0.5 per RESEARCH.md anti-pattern 5
    - Compute weighted average, map back: >= 3.5 = A, >= 2.5 = B, >= 1.5 = C, < 1.5 = D
    - Return tuple of (overall_grade, actual_weights_dict)
    - Read thresholds from capital_allocation_config.OVERALL_GRADE_A/B/C_THRESHOLD
