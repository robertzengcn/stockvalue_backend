    The endpoint function `analyze_capital_allocation`:

    **(a) Input validation and stock setup:**
    - Extract ticker from request, uppercase it
    - Determine market (HK or A_SHARE) from ticker suffix
    - Call `ensure_stock_exists(ticker, market, data_service, db)` to ensure stock is in DB
    - Determine fiscal_year: use request.year if provided, else today's year - 1

    **(b) Buyback yield dimension (CAPEX-01, D-01, D-02):**
    - `buyback_data = await data_service.get_buyback_data(ticker)` -- returns dict with repurchase_amount, data_quality
    - Get market cap: `await data_service.get_current_price(ticker)` for price, `await data_service.get_shares_outstanding(ticker)` for shares, compute `market_cap = price * shares_outstanding`
    - If either call fails, log warning and set market_cap = None
    - `buyback_yield_value = calculate_buyback_yield(buyback_data.get("repurchase_amount"), market_cap)`
    - `buyback_grade = grade_buyback_yield(buyback_yield_value)`
    - Build `BuybackYieldResult(buyback_yield=buyback_yield_value, repurchase_amount=buyback_data.get("repurchase_amount"), market_cap=market_cap, data_quality=buyback_data.get("data_quality", "NO_DATA"), grade=buyback_grade)`

    **(c) Dividend stability dimension (CAPEX-02, D-03, D-04):**
    - DB-first per D-03: `dividend_repo = DividendRepository(db)`, `dividend_records = await dividend_repo.get_by_ticker(ticker, limit=10)`
    - Extract DPU values from records: filter by fiscal_year, group by fiscal_year, sum dividend_per_share per year
    - Build `dpu_values: list[float]` and `dpu_years: list[int]` sorted by year ascending
    - If fewer than 3 years of DB data: fall back to AKShare `data_service._akshare.get_dividend_history(symbol)` and parse
    - If still insufficient (< 3 data points): use INSUFFICIENT_DATA classification
    - `trend_data = classify_dividend_stability(dpu_values, dpu_years)`
    - `dividend_grade = grade_dividend_stability(trend_data["classification"])`
    - Build `DividendStabilityResult(classification=trend_data["classification"], slope=trend_data.get("slope"), p_value=trend_data.get("p_value"), data_points=trend_data.get("data_points", 0), dpu_values=dpu_values, grade=dividend_grade)`

    **(d) Expansion discipline dimension (CAPEX-03, D-05, D-06):**
    - Get ROIC from Phase 9: `roic_repo = ROICResultRepository(db)`, `roic_result = await roic_repo.get_latest_for_ticker(ticker)`
    - Extract `roic_value = roic_result.roic if roic_result else None`, `wacc_value = roic_result.wacc if roic_result else 0.0`
    - If roic_result is None: log info "No ROIC result for {ticker}, expansion discipline will use INSUFFICIENT_DATA"
    - Get 2-year CapEx: `capex_data = await data_service.get_multi_year_capex(ticker, years=2)`
    - Extract capex_current (most recent year) and capex_previous (second year) from capex_data
    - If capex_data has fewer than 2 entries: set capex_current and capex_previous to None
    - `blind_expansion = detect_blind_expansion(roic_value, wacc_value, capex_current, capex_previous)`
    - `expansion_grade = grade_expansion_discipline(blind_expansion)`
    - Build `ExpansionDisciplineResult(alert=blind_expansion["alert"], roic_wacc_spread=blind_expansion.get("roic_wacc_spread"), capex_yoy_growth=blind_expansion.get("capex_yoy_growth"), capex_current=blind_expansion.get("capex_current"), capex_previous=blind_expansion.get("capex_previous"), reason=blind_expansion.get("reason"), grade=expansion_grade)`

    **(e) Combined scorecard (CAPEX-04, D-07, D-08):**
    - `overall_grade, weighting = calculate_capital_allocation_score(buyback_grade if buyback_data.get("data_quality") != "NO_DATA" else None, dividend_grade, expansion_grade)`
    - Note: pass None for buyback_grade only when NO_DATA (no buyback programs at all), not when yield is 0

    **(f) Build response:**
    ```python
    result = CapitalAllocationResult(
        ticker=ticker,
        fiscal_year=fiscal_year,
        buyback_yield=buyback_yield_result,
        dividend_stability=dividend_stability_result,
        expansion_discipline=expansion_discipline_result,
        overall_grade=overall_grade,
        weighting=weighting,
        audit_trail={
            "buyback_data_source": buyback_data.get("data_quality"),
            "dividend_data_source": "db" if len(dividend_records) >= 3 else "akshare_fallback",
            "roic_data_source": "phase9_db" if roic_result else "unavailable",
            "capex_data_points": len(capex_data),
        },
        calculated_at=datetime.now(timezone.utc),
    )
    ```

    **(g) Persist to database (non-blocking):**
    - `capex_repo = CapitalAllocationRepository(db)`
    - Create `CapitalAllocationScoreCreate(analysis_id=uuid4(), ticker=ticker, fiscal_year=fiscal_year, buyback_yield_data=buyback_yield_result.model_dump(), dividend_stability_data=dividend_stability_result.model_dump(), expansion_discipline_data=expansion_discipline_result.model_dump(), overall_grade=overall_grade.value, weighting=weighting, audit_trail=result.audit_trail)`
    - `await capex_repo.upsert_by_ticker_year(create_data)`
    - `await db.commit()`
    - Wrap in try/except, rollback on error, log error

    **(h) Return:**
    - `return ApiResponse(success=True, data=result)`

    **Error handling (same pattern as roic_routes.py):**
    - `DataValidationError` -> `ApiResponse(success=False, error=str(e))`
    - `ExternalAPIError` -> `ApiResponse(success=False, error="Failed to fetch financial data. Please try again later.")`
    - Generic `Exception` -> `ApiResponse(success=False, error="An internal error occurred. Please try again later.")`
