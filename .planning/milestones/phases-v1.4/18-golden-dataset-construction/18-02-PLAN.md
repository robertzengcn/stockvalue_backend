**Script design**:
```python
"""Freeze AKShare financial data for golden test datasets.

Fetches income statement, balance sheet, and cash flow data from AKShare
for each stock listed in manifest.yaml and writes the raw JSON responses
to the appropriate golden directory.

Usage:
    # Freeze all stocks in manifest
    uv run python tests/golden/freeze_akshare_data.py

    # Freeze a specific stock
    uv run python tests/golden/freeze_akshare_data.py --ticker 600519.SH

    # Freeze with a different year
    uv run python tests/golden/freeze_akshare_data.py --ticker 600519.SH --year 2023

    # Force overwrite existing frozen data
    uv run python tests/golden/freeze_akshare_data.py --force
"""
```

Implementation requirements:
1. Read manifest.yaml to discover stocks (or use --ticker for a single stock)
2. For each stock/year: call `akshare.stock_profit_sheet_by_report_em`, `akshare.stock_balance_sheet_by_report_em`, `akshare.stock_cash_flow_sheet_by_report_em`
3. Use `eastmoney_hsf10_symbol()` from `stockvaluefinder.external.akshare_client` for symbol conversion
4. Filter results to the target period (e.g., REPORT_DATE contains "20231231" or "2023-12-31")
5. Write raw API responses as JSON:
   - `{GOLDEN_DIR}/{ticker}/{year}/raw_akshare_income.json`
   - `{GOLDEN_DIR}/{ticker}/{year}/raw_akshare_balance.json`
   - `{GOLDEN_DIR}/{ticker}/{year}/raw_akshare_cashflow.json`
6. Each JSON file contains a list of dicts (the to_dict("records") output from AKShare DataFrame)
7. Include metadata at the top of each JSON:
   ```json
   {
     "_metadata": {
       "ticker": "600519.SH",
       "fiscal_year": 2023,
       "period": "20231231",
       "source": "akshare.stock_profit_sheet_by_report_em",
       "frozen_date": "2026-05-21T12:00:00Z",
       "record_count": 1
     },
     "records": [...]
   }
   ```
8. Skip if file exists unless --force flag is given
9. Print summary after freezing: "Froze 14 stocks (42 files) in X.Xs"
10. Use argparse for CLI arguments (no external CLI framework needed)

**IMPORTANT for JSON format**: The frozen JSON files must contain the EXACT same dict-of-records format that `akshare_client.get_profit_sheet()` returns (i.e., `df.to_dict("records")`). This is critical because L2 tests will load these files and pass them through the same `_extract_akshare_*` / `_coalesce_akshare_field` functions that the production code uses. The `_metadata` wrapper must NOT interfere with this -- either put metadata outside the records list, or have the test loader skip the `_metadata` key.

If AKShare API calls fail for any stock (network issues, rate limiting), the script should:
- Log a warning with the ticker and error
- Continue to the next stock
- Print a summary at the end with successes and failures
- Exit with code 1 if any stock failed

**After freezing, update manifest.yaml**: Change `provenance: "pending"` to `provenance: "frozen_akshare"` for all stocks where the 3 JSON files were successfully written. Do NOT change `l3_verified` -- that only changes when hand-verified values are populated.

Handle rate limiting: Add a 1-second sleep between API calls for different stocks to avoid being rate-limited by East Money.

**Part A: Compute 600519.SH expected_metrics.yaml from frozen data**

This is the anchor stock approach: use the frozen AKShare JSON as the DATA SOURCE and run the actual production calculate_* functions to produce EXACT expected values. No approximate "~" values. No hand calculations. The frozen AKShare data IS the exchange filing data (AKShare sources from East Money which sources from exchange filings).

Steps:
1. Load the three frozen JSON files for 600519.SH/2023:
   - raw_akshare_income.json
   - raw_akshare_balance.json
   - raw_akshare_cashflow.json
2. Also load the 2022 data (needed for year-over-year M-Score indices). This requires fetching the 2022 data using the freeze script with --year 2022 --ticker 600519.SH, OR extracting 2022 data from the current frozen files if they contain multiple years.

   IMPORTANT: AKShare `stock_*_by_report_em` endpoints return data for multiple report periods. The frozen JSON for 2023 likely contains rows for both 2023-12-31 and 2022-12-31. Extract both years from the frozen file.

3. Use the same field extraction that the production AKShareClient uses to build standardized dicts. Map the AKShare column names to the standardized field names used by calculate_* functions:
   - Revenue: 营业收入
   - Net Income: 净利润
   - Cost of Goods: 营业成本
   - SGA Expense: 销售费用 + 管理费用
   - Total Assets: 资产总计
   - Total Current Assets: 流动资产合计
   - Accounts Receivable: 应收账款
   - PPE: 固定资产
   - Total Liabilities: 负债合计
   - Operating Cash Flow: 经营活动产生的现金流量净额
   - Goodwill: 商誉
   - Cash: 货币资金

4. Call each calculate_* function with the extracted data:

   a. **M-Score indices**: Call `calculate_mscore_indices(current_report_2023, previous_report_2022, source_name="AKShare")`. Extract exact values for dsri, gmi, aqi, sgi, depi, sgai, lvgi, tata from the returned dict.

   b. **M-Score**: Call `calculate_beneish_m_score(current_financials, previous_financials)` with the index values. Extract m_score.

   c. **F-Score**: Call `calculate_piotroski_f_score(report_2023, previous_report_2022)`. Extract f_score.

   d. **detect_存贷双高**: Call `detect_存贷双高(report_2023)`. Extract the boolean/result.

   e. **Goodwill ratio**: Call `calculate_goodwill_ratio(report_2023)`. Extract goodwill_ratio.

   f. **Profit-cash divergence**: Call `detect_profit_cash_divergence(report_2023)`. Extract result.

   g. **NOPAT, Invested Capital, ROIC**: Extract the raw financial values needed and compute using the production formulas. For non-financial stocks: NOPAT = (TOTAL_PROFIT + FINANCE_EXPENSE) * (1 - effective_tax_rate), Invested Capital = Total Equity + Interest-bearing Debt, ROIC = NOPAT / Invested Capital.
