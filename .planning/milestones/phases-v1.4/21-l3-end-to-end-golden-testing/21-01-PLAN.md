3. **compute_metrics_from_frozen** -- Callable `(ticker, year, is_financial) -> dict[str, float | None]` that runs the full L3 pipeline. Steps:
   a. Load current year frozen data via frozen_data_loader
   b. Build standardized report via `build_standardized_report_from_frozen(income, balance, cashflow, ticker, year)`
   c. Attempt to load previous year frozen data. If previous year JSON does not exist, set all year-over-year metrics to None and return early for those.
   d. If previous year data exists, build previous report the same way
   e. Call `calculate_mscore_indices(current_report, previous_report, source_name="AKShare(frozen)")` to get 8 sub-indices (dsri, gmi, aqi, sgi, depi, sgai, lvgi, tata)
   f. Call `calculate_beneish_m_score` with a mapped dict. The calculate_mscore_indices returns keys like "dsri" but calculate_beneish_m_score expects keys like "days_sales_receivables_index". Use this explicit mapping:
   ```python
   INDEX_KEY_MAP = {
       "dsri": "days_sales_receivables_index",
       "gmi": "gross_margin_index",
       "aqi": "asset_quality_index",
       "sgi": "sales_growth_index",
       "depi": "depreciation_index",
       "sgai": "sga_expense_index",
       "lvgi": "leverage_index",
       "tata": "total_accruals_to_assets",
   }
   m_score_input = {INDEX_KEY_MAP[k]: v for k, v in indices_result.items() if k in INDEX_KEY_MAP}
   m_score_result = calculate_beneish_m_score(m_score_input, {})
   ```
   g. Call `calculate_piotroski_f_score(current_report, previous_report)` -- extract `result["f_score"]` (the key is "f_score", NOT "total_score").
   h. Call `detect_存贷双高(current_report, previous_report)` -- extract `result["存贷双高"]` (the boolean flag key is "存贷双高").
   i. Call `calculate_goodwill_ratio(Decimal(str(current_report.get("goodwill", 0))), Decimal(str(current_report.get("equity_total", current_report.get("total_parent_equity", 0)))))` -- extract `result["ratio"]`. NOTE: goodwill and equity are string values in the standardized report and must be converted via `Decimal(str(...))`.
   j. Call `detect_profit_cash_divergence(current_net_income, previous_net_income, current_ocf, previous_ocf)` -- extract `result["divergence"]` (the key is "divergence").
   k. For ROIC: call `roic_inputs_from_frozen(income, balance)`, then `calculate_nopat(profit_data, is_financial)`, `calculate_invested_capital(balance_data)`, `calculate_roic(nopat, ic, negative_ic)`.
   l. Metrics with null expected values in expected_metrics.yaml (wacc, present_value, terminal_value, margin_of_safety, net_dividend_yield, yield_gap, buyback_yield, capital_allocation_score, resonance_score, dcf_adjustment, alpha_score) should be set to None in the returned dict since they require external market data.
   m. Return flat dict of metric_name -> computed_value (float or None).

4. **assert_metric_within_tolerance** -- Callable `(metric_name, expected, computed, registry) -> ComparisonResult`:
```python
def _assert(metric_name, expected, computed, registry):
    result = registry.check(metric_name, expected, computed)
    assert result.passed, (
        f"Metric '{metric_name}' outside tolerance: "
        f"expected={expected}, computed={computed}, "
        f"delta={result.delta}, tolerance={result.tolerance_applied}"
    )
    return result
```

IMPORTANT: For boolean metrics (detect_存贷双高, profit_cash_divergence), convert to float (True=1.0, False=0.0) before calling registry.check(). For integer metrics (f_score), pass as float.
