<objective>
Build the core reconcile logic: a pure-function pipeline that loads golden expected values, computes metrics from frozen OR live data, and compares them using the MetricRegistry tolerance system.

Purpose: The CLI tool needs a testable, importable core module that does all the reconciliation work without any CLI/output concerns. This separation allows both the Typer CLI entry point and unit tests to call the same logic. The module supports two modes: frozen (uses golden JSON files, no network) and live (uses ExternalDataService to fetch real AKShare data).

Output: `reconcile_core.py` with `ReconcileResult` dataclass, `reconcile()` function (frozen mode), `reconcile_live()` function (live mode), plus unit tests proving it works end-to-end for 600519.SH/2023.
</objective>

```python
class MetricRegistry(BaseModel):
    metrics: dict[str, MetricDefinition]
    def get(self, name: str, sector: str | None = None) -> MetricDefinition
    def check(self, name: str, expected: float, computed: float, sector: str | None = None) -> ComparisonResult
    def p0_metrics(self) -> list[tuple[str, MetricDefinition]]
    def all_metrics(self) -> list[tuple[str, MetricDefinition]]

class MetricDefinition(BaseModel):
    display_name: str
    category: str
    priority: str  # "P0", "P1", "P2"
    tolerance: Tolerance
    audit_trail_required: bool = False

class Tolerance(BaseModel):
    absolute: float | None = None
    relative: float | None = None
```
