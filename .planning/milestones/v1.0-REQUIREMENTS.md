## Out of Scope

| Feature | Reason |
|---------|--------|
| Real-time tick-by-tick prices | Value investors don't need minute-level data |
| Technical analysis (K-lines, MACD, RSI) | Contradicts value investing approach |
| AI buy/sell/hold recommendations | Regulatory risk in China |
| Automated trading execution | Regulatory overhead and liability |
| Social/community features | Scope creep; moderation cost |
| Multi-market support (US, Japan) | Different accounting standards |
| Chat-based conversational interface | Expensive per-query; hallucination risk |
| User authentication | Single-user system for MVP |
| Frontend application | API-only for this milestone |
| LLM performing financial calculations | Architecture principle |
