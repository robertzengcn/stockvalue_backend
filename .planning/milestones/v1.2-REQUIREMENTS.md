## v1.2 Requirements (All Complete)

### Value Creation (ROIC-WACC)

- [x] **ROIC-01**: User can calculate ROIC (NOPAT / Invested Capital) from AKShare financial data for any CSI 300 stock — Phase 9
- [x] **ROIC-02**: User can calculate true WACC (weighted cost of equity + after-tax cost of debt) with debt/equity ratio from balance sheet — Phase 9
- [x] **ROIC-03**: User can view ROIC-WACC spread with classification (value creating vs destroying) — Phase 9
- [x] **ROIC-04**: System detects financial sector stocks and applies correct NOPAT formula (OPERATE_PROFIT instead of EBIT-based) — Phase 9
- [x] **ROIC-05**: System handles edge cases: negative invested capital, NaN debt fields (debt-free companies) — Phase 9
- [x] **ROIC-06**: User can view 3-year ROIC-WACC spread trend with moat detection — Phase 9

### Capital Allocation

- [x] **CAPEX-02**: User can view 5-year dividend per unit stability trend with growth/decline/stable classification — Phase 10
- [x] **CAPEX-03**: System alerts on blind expansion (ROIC < WACC AND CapEx growth exceeding threshold) — Phase 10
- [x] **CAPEX-04**: User can view capital allocation scorecard combining buyback yield, dividend stability, and expansion discipline — Phase 10

- [x] **POL-04**: System auto-adjusts DCF terminal growth rate based on policy resonance — Phase 11
