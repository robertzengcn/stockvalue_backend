## Milestone Summary

**Key Decisions:**
- Phase 9 first: ROIC-WACC is foundation dependency for Capital Allocation (blind expansion check)
- scipy >=1.15.0: Only new dependency, needed for 3-year trend line regression
- Fixed weights (40/30/20/10): Transparent, auditable, no user configuration needed
- Policy docs in separate Qdrant collection: Different metadata schema from annual reports
- Direct route handler function calls for orchestration, not HTTP self-call
- Non-blocking persistence: DB errors logged but API response still returned

**Issues Resolved:**
- AKShare stock_individual_info_em() does NOT return business descriptions — switched to stock_profile_cninfo()
- Plan checker found missing db/models/__init__.py registration — fixed before execution
- IEEE 754 floating point precision in ROIC-WACC normalization — fixed with round(..., 2)

**Issues Deferred:**
- LLM prompt for DCF parameter extraction from policy text needs iterative testing
- AKShare stock_repurchase_em() data quality varies — cached with 24h TTL

**Technical Debt Incurred:**
- None significant — all patterns follow established conventions
