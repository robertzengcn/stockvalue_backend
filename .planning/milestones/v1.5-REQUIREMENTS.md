# Requirements: v1.5 Market Index Value Scanner

**Milestone:** v1.5
**Created:** 2026-06-04
**Completed:** 2026-06-05
**Status:** SHIPPED

## Index Data & Market Snapshot

### IDX-01: Index Constituent Synchronization [COMPLETE - Phase 25]
User can sync CSI 300 and CSI 500 constituent lists from AKShare, with each sync recording the effective date. Historical constituent changes are retained. A stock can belong to multiple indices simultaneously.

### IDX-02: Constituent History Tracking [COMPLETE - Phase 25]
When constituents change between syncs, previously active members are marked as removed with a removal date. The system preserves the last-known-good constituent list if sync fails.

### IDX-03: Batch Market Data Snapshot [COMPLETE - Phase 27]
User can fetch batch market snapshots (PE TTM, PB, dividend yield, market cap, turnover, ST status, suspension status) for all constituents of a given index in a single operation, with rate-limited API calls and caching.

### IDX-04: Valuation Percentile Calculation [COMPLETE - Phase 27]
User can calculate historical PE/PB percentile ranking for each stock within its index, showing where the current valuation sits relative to its 5-year history.

## Screening Funnel

### SCR-01: Market Coarse Screening [COMPLETE - Phase 26]
User can run a coarse screen that filters out ST stocks, suspended stocks, stocks with missing price data, stocks below minimum liquidity threshold, and stocks with persistently negative operating cash flow. Low PE, low PB, high dividend yield, and significant price drawdown stocks are prioritized.

### SCR-02: DCF Value Confirmation [COMPLETE - Phase 27]
User can run DCF valuation on the top N stocks from the coarse screen, calculating intrinsic value, WACC, safety margin, and valuation level. Stocks with safety margin >= 30% are flagged as potentially undervalued.

### SCR-03: Risk and Quality Review [COMPLETE - Phase 27]
User can run a risk and quality review on value-confirmed stocks that checks ROIC-WACC spread, M-Score, cash flow divergence, leverage, and dividend sustainability. Only stocks passing risk review enter the candidate list.

### SCR-04: Configurable Screening Thresholds [COMPLETE - Phase 25]
All screening thresholds are configurable via a frozen dataclass config, not hardcoded in business logic.

## Scoring & Explanation

### SCR-05: Composite Candidate Scoring [COMPLETE - Phase 26]
User can view a composite score for each candidate stock, calculated from 5 weighted dimensions: safety margin (35%), Alpha score (25%), risk penalty (20%), dividend yield gap (10%), and valuation percentile (10%).

### SCR-06: Structured Reason Generation [COMPLETE - Phase 26]
Each candidate stock has machine-generated structured reasons and risk flags derived from deterministic metrics, not LLM-generated.

### SCR-07: Configurable Scoring Weights [COMPLETE - Phase 26]
Scoring weights and candidate threshold are configurable with sensible defaults.

## Execution & API

### EXE-01: Scheduled Daily Light Scan [COMPLETE - Phase 28]
Daily post-market-close light scan runs as an arq cron job.

### EXE-02: Scheduled Weekly Deep Scan [COMPLETE - Phase 28]
Weekly deep scan runs as an arq cron job supplementing the daily scan.

### EXE-03: Manual Scan Trigger [COMPLETE - Phase 28]
Admin users can manually trigger a scan via API with configurable parameters.

### EXE-04: Scan Run Lifecycle Tracking [COMPLETE - Phase 25]
Each scan run has a unique run ID and tracks status through pending -> running -> completed/partial_failed.

### EXE-05: Scan Results API - Runs [COMPLETE - Phase 28]
User can query scan run history with pagination and filtering.

### EXE-06: Scan Results API - Candidates [COMPLETE - Phase 28]
User can query candidate lists by run ID with pagination, filtering, and sorting.

### EXE-07: Scan Results API - Candidate Detail [COMPLETE - Phase 28]
User can query full candidate detail including structured reasons and screening snapshot.

### EXE-08: Candidate-to-Watchlist Integration [COMPLETE - Phase 28]
User can add a candidate stock to their watchlist via API with duplicate handling.
