# Milestone v1.5: Market Index Value Scanner

**Status:** SHIPPED 2026-06-05
**Phases:** 25-28
**Total Plans:** 11

## Overview

Build a systematic scanner that automatically discovers undervalued stocks across CSI 300 and CSI 500 index pools using a 3-layer screening funnel (market coarse screen -> value confirmation -> quality/risk review), with composite scoring, deterministic reason generation, scheduled arq worker jobs, and REST API endpoints.

### Phase 26: Screening & Scoring Engine

**Goal**: Stocks can be filtered through the coarse screen and ranked by composite score with deterministic, structured explanations
**Depends on**: Phase 25
**Plans**: 3 plans

Plans:
- [x] 26-01: ScoringWeightsConfig, extended MarketScannerConfig, screening/scoring Pydantic models
- [x] 26-02: Coarse screener (SCR-01) and composite scorer (SCR-05, SCR-07)
- [x] 26-03: Deterministic reason generator (SCR-06)

**Details:**
- ScoringWeightsConfig frozen dataclass with 5 weight fields (safety_margin 35%, alpha 25%, risk_penalty 20%, yield_gap 10%, valuation_percentile 10%)
- Coarse screener: 6 hard-exclusion rules (ST, suspended, missing data, low liquidity, negative cash flow, below market cap) + 4 soft prioritization signals (PE, PB, dividend yield, drawdown)
- Composite scorer: 5 normalization functions with NaN guards, configurable weighted sum
- Reason generator: 4 domain helpers (valuation, risk, yield, composite) with compliance enforcement (always >= 1 risk flag), zero LLM imports
- 248 tests passing

### Phase 27: Market Scanner Service

**Goal**: A complete scan orchestrates constituent sync, batch data fetching, deep analysis (DCF, risk, yield, Alpha), and candidate persistence -- with single-stock failure isolation
**Depends on**: Phase 26
**Plans**: 3 plans

Plans:
- [x] 27-01: Batch data fetcher (IDX-03) and valuation percentile calculator (IDX-04)
- [x] 27-02: Quality review pure-function gate (SCR-03)
- [x] 27-03: Scan orchestrator with DCF top-N, failure isolation, and candidate persistence (SCR-02)

**Details:**
- BatchDataFetcher: single AKShare stock_zh_a_spot_em() bulk call for all A-shares, per-ticker failure isolation
- calculate_valuation_percentile: scipy.stats.percentileofscore with 60-point minimum
- Quality review gate: 6 deterministic checks (ROIC-WACC spread, M-Score, cash flow divergence, risk level, leverage, dividend sustainability)
- ScanOrchestrator: full pipeline coordination (constituents -> batch fetch -> coarse screen -> rank top N -> DCF + risk + quality review -> composite score -> generate reasons -> persist candidates), per-stock failure isolation with asyncio.Semaphore

## Milestone Summary

**Key Decisions:**
- Market Scanner as independent package (not in pipeline/watcher)
- Reuse existing analysis services (DCF, Risk, Yield, Alpha) -- scanner orchestrates, does not recalculate
- arq worker for scheduled scans alongside existing disclosure watcher
- Single-stock failure isolation for batch processing
- Frozen dataclass config for all thresholds and weights
- No FK from index_constituents.ticker to stocks.ticker -- sync may run before stock records exist
- Combined TDD RED+GREEN into single commits due to pre-commit mypy hook requiring type-complete code
- Used sqlalchemy asc()/desc() standalone functions for JSONB text() sort expressions
- Used getattr(req.app.state, "arq_pool", None) for graceful arq pool unavailability
- Accepted global watchlist (no user_id) for MVP scanner watchlist integration

**Issues Resolved:**
- text() clause does not support .desc()/.asc() methods -- fixed with sqlalchemy.desc()/asc() standalone functions
- FastAPI rejects Request | None = None as route parameter -- fixed with getattr pattern
- valuation_percentile None defaults to 50.0 (neutral) to avoid penalizing stocks without peer data

**Issues Deferred:**
- Event-triggered rescan (price drop > 10%, earnings release, index rebalance)
- Candidate change summary between scans (new entrants, dropouts, score changes)
- Industry theme index support (CSI 1000, CSI Dividend)
- User-custom stock pool scanning
- LLM narrative for candidate explanation (optional enhancement)
- Intraday real-time scanning

**Technical Debt Incurred:**
- Global watchlist (no user_id) for MVP scanner watchlist integration
- BatchDataFetcher dividend_yield defaults to 0.0 (not in AKShare bulk API)
- price_vs_52w_high defaults to 1.0 (neutral, not available from bulk API)
