# Milestone v1.6: Equity Pledge Risk Analysis

**Status:** SHIPPED 2026-06-08
**Phases:** 29-31
**Total Plans:** 8

## Overview

Add equity pledge risk as an independent risk dimension to the existing risk analysis pipeline, enabling users to assess controlling shareholder pledge pressure and closeout risk for A-share stocks.

## Phases

### Phase 29: Pledge Data Foundation (3/3 plans)
- Pydantic models, AKShare client methods, field mapping, ticker normalization
- ExternalDataService pledge interfaces, Redis caching, date discovery
- Gap closure (code review fixes, deviation recording)

### Phase 30: Pledge Risk Calculation (2/2 plans)
- Multi-dimensional grading (company ratio, holder ratio, closeout margin)
- Combination upgrade rules, risk merge, red flags, HK unsupported
- 205 tests with 100% coverage

### Phase 31: Persistence & API Integration (3/3 plans)
- ORM models, Alembic migration 021, repositories
- Risk API integration with graceful degradation
- Narrative prompt extension with LLM guardrails
- 14 UAT tests passed

## Key Decisions
- pledge_risk/risk_level_breakdown stored as nullable JSONB
- Pledge computation separated from persistence for transaction safety
- include_pledge_risk defaults True for backward-compatible enrichment
- Narrative three-tier conditional: unsupported HK, UNAVAILABLE, full data
