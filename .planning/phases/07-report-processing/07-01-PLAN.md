<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| worker -> CNInfo | External HTTP download, untrusted response |
| worker -> filesystem | Writing downloaded PDF to local disk |
| worker -> PostgreSQL | Database writes for metadata and state |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-07-01 | Denial of Service | download_report | mitigate | Validate Content-Type is PDF before processing; reject HTML responses (Pitfall 1) |
| T-07-02 | Tampering | file_path construction | mitigate | Ticker validated by regex from PipelineTaskCreate; path uses ticker/fy/type segments only |
| T-07-03 | Tampering | PDF URL construction | mitigate | URL must match static.cninfo.com.cn domain; no arbitrary URLs from user input |
| T-07-04 | Denial of Service | large PDF / zip bomb | accept | File size limited by httpx timeout and MAX_FILE_SIZE_MB in DocumentService downstream |
</threat_model>
