Replace the parse_report stub in worker.py with a fully functional implementation per PIPE-07:

1. Implement parse_report(ctx, task_id):
   - Get session_factory from ctx
   - In async with session_factory() as session:
     a. repo = PipelineTaskRepository(session); task = await repo.get_by_id(task_id)
     b. If task is None, log error and return
     c. doc_repo = PipelineDocumentRepository(session)
     d. document = await doc_repo.get_by_task_id(task_id)
     e. If document is None: transition to FAILED with "No document record found", commit, return
     f. file_path = document.file_path; if None or not Path(file_path).exists(): transition to FAILED with "PDF file not found", commit, return
     g. Read pdf_bytes from file_path: `pdf_bytes = Path(file_path).read_bytes()`
     h. Create a SEPARATE session for DocumentService (Pitfall 3: DocumentService writes to documents table, not pipeline tables)
        - async with session_factory() as ds_session:
        - doc_service = DocumentService(ds_session)
        - result = await doc_service.process_upload(
            document_id=str(document.document_id),
            ticker=task.ticker,
            file_name=Path(file_path).name,
            file_path=file_path,
            pdf_bytes=pdf_bytes,
          )
        - await ds_session.commit()  -- commit DocumentService's work
     i. Transition to ANALYZING via repo.transition_state(task_id, PipelineState.ANALYZING, current_stage="analyzing")
     j. session.commit()  -- commit pipeline state
     k. Enqueue analyze_report: create_pool(RedisSettings), enqueue_job("analyze_report", task_id, _job_id=f"analyze:{task.business_key}"), close pool
   - On any Exception: repo.transition_state(task_id, PipelineState.FAILED, error_message=str(e)), session.commit(), raise
