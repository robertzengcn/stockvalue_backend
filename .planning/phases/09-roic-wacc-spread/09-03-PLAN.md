   The route handler `analyze_roic` must:
   
   a) **Extract and validate inputs:**
      - Parse `request.ticker` and `request.year`
      - Fetch current-year ROIC inputs: `roic_inputs = await data_service.get_roic_inputs(ticker, year)`
      - The `roic_inputs` dict contains profit sheet and balance sheet fields

   b) **Detect financial sector (D-09):**
      - Get stock from DB: `stock_repo = StockRepository(db); stock = await stock_repo.get_by_ticker(ticker)`
      - If stock not in DB yet: call `await ensure_stock_exists(ticker, market, data_service, db)` then re-fetch
      - `is_fin = is_financial_sector(stock.industry)` -- NOTE: use `stock.industry`, NOT `stock.sector` (research verified the field name is `industry`)

   c) **Compute NOPAT (D-10):**
      - `nopat, nopat_audit = calculate_nopat(roic_inputs, is_financial=is_fin)`

   d) **Compute Invested Capital (D-08, D-11):**
      - `invested_capital, negative_ic = calculate_invested_capital(roic_inputs)`

   e) **Compute ROIC:**
      - `roic_value = calculate_roic(nopat, invested_capital, negative_ic)`

   f) **Compute WACC with debt weighting (D-01, D-02, D-03):**
      - Get risk_free_rate: from `roic_inputs` or use a default (e.g., from rate_client or settings). For MVP, use the existing rate fetch pattern from valuation routes: `rate_data = await data_service.get_risk_free_rate()`.
      - Get beta: from `roic_inputs.get("beta", settings.valuation.DEFAULT_BETA)`
      - Get ERP: `settings.valuation.DEFAULT_MARKET_RISK_PREMIUM`
      - Compute Kd (D-02): `finance_expense = _to_float(roic_inputs.get("FINANCE_EXPENSE"))`, `total_debt = invested_capital - _to_float(roic_inputs.get("TOTAL_PARENT_EQUITY")) + _to_float(roic_inputs.get("TREASURY_SHARES"))`. If total_debt > 0: `kd = abs(finance_expense) / total_debt` else `kd = None`.
      - Compute debt_weight: If invested_capital and invested_capital > 0: `debt_weight = total_debt / (invested_capital + total_debt)` (approximation: D / (D+E+D)). Actually, simpler: `total_equity = _to_float(roic_inputs.get("TOTAL_PARENT_EQUITY"))`, if total_equity + total_debt > 0: `debt_weight = total_debt / (total_equity + total_debt)`.
      - Compute tax_rate: from NOPAT calculation (already computed).
      - Call `wacc_value = calculate_wacc(rf, beta, erp, debt_weight, kd or 0.0, tax_rate)`
      - Build `WACCBreakdown` with all components (D-03): ke, kd, equity_weight, debt_weight, de_ratio, tax_rate, wacc

   g) **Compute spread (D-03):**
      - `spread, classification = calculate_roic_wacc_spread(roic_value, wacc_value)`

   h) **Compute 3-year trend (D-06):**
      - `multi_year = await data_service.get_multi_year_roic_inputs(ticker, years=3)`
      - For each year: compute spread using same formula
      - `trend_result = analyze_roic_trend(spreads, years_list)`
      - Build `MoatTrendResult`

   i) **Build response:**
      - Create `ROICAnalysisResult` with all computed values
      - Return `ApiResponse(success=True, data=result)`

   j) **Persist to database:**
      - Try/except block: create `ROICResultCreate`, call `roic_repo.upsert_by_ticker_year()`, commit
      - On failure: rollback and log error (non-blocking -- return result even if DB save fails)

   k) **Error handling** (follow risk_routes pattern exactly):
      - `DataValidationError` -> `ApiResponse(success=False, error=str(e))`
      - `ExternalAPIError` -> `ApiResponse(success=False, error="Failed to fetch financial data...")`
      - Generic `Exception` -> `ApiResponse(success=False, error="An internal error occurred...")`

   Import `_to_float` from `risk_service` for NaN normalization.
