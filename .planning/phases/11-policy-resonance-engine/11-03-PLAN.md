## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| User -> Upload endpoint | Untrusted file upload, must validate type and size |
| Policy text -> LLM | User-controlled content sent to DeepSeek (prompt injection risk) |
| LLM response -> Application | Untrusted LLM output parsed as structured data |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-11-07 | Tampering | PDF upload | mitigate | Validate file type (extension + content_type), enforce max size (100MB per RAGConfig), sanitize filename |
| T-11-08 | Spoofing | Policy content -> LLM | accept | LLM output is never executed as code; only parsed as JSON. Prompt injection cannot affect system behavior |
| T-11-09 | Denial of Service | Upload endpoint | mitigate | Max file size enforced by RAGConfig.MAX_FILE_SIZE_MB, chunking limits compute cost |
| T-11-10 | Tampering | Resonance request ticker | mitigate | Pydantic Field pattern validation r"^\d{6}\.(SH|SZ|HK)$" on ResonanceRequest |
</threat_model>
