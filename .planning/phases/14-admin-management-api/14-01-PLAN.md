1. Add two methods to `UserRepository` in `stockvaluefinder/stockvaluefinder/repositories/user_repo.py`:

   a. `list_users(page: int = 1, limit: int = 20) -> tuple[list[UserDB], int]`:
      - Import `offset` from sqlalchemy (add to existing import line: `from sqlalchemy import func, select, offset` -- or use `.offset()` method on the select)
      - Query: `SELECT * FROM users WHERE deleted_at IS NULL ORDER BY created_at DESC LIMIT {limit} OFFSET {(page-1)*limit}`
      - Count query: `SELECT COUNT(*) FROM users WHERE deleted_at IS NULL`
      - Return tuple of (user_list, total_count)
      - Use `result.scalars().all()` for the list query
      - Validate: if page < 1, set page=1; if limit < 1, set limit=1; if limit > 100, set limit=100
      - Implementation:
        ```python
        async def list_users(
            self, page: int = 1, limit: int = 20
        ) -> tuple[list[UserDB], int]:
            page = max(1, page)
            limit = max(1, min(100, limit))
            offset_val = (page - 1) * limit

            count_stmt = select(func.count()).select_from(UserDB).where(
                UserDB.deleted_at.is_(None)
            )
            count_result = await self._session.execute(count_stmt)
            total = count_result.scalar_one()

            list_stmt = (
                select(UserDB)
                .where(UserDB.deleted_at.is_(None))
                .order_by(UserDB.created_at.desc())
                .offset(offset_val)
                .limit(limit)
            )
            list_result = await self._session.execute(list_stmt)
            users = list(list_result.scalars().all())

            return users, total
        ```

   b. `soft_delete(user_id: UUID) -> UserDB | None`:
      - Find user by id where deleted_at IS NULL
      - If found, set `user.deleted_at = datetime.utcnow()`
      - Import `datetime` at top if not already imported
      - Flush + refresh
      - If not found, return None
      - Implementation:
        ```python
        async def soft_delete(self, user_id: UUID) -> UserDB | None:
            from datetime import datetime

            stmt = select(UserDB).where(
                UserDB.id == user_id, UserDB.deleted_at.is_(None)
            )
            result = await self._session.execute(stmt)
            user = result.scalar_one_or_none()
            if user is None:
                return None
            user.deleted_at = datetime.utcnow()
            await self._session.flush()
            await self._session.refresh(user)
            return user
        ```
