    Implement the following frozen Pydantic V2 model hierarchy (per D-05):

    1. `Tolerance(BaseModel)` -- frozen=True
       - `absolute: float | None = None` -- absolute tolerance (e.g., 0.05 for M-Score)
       - `relative: float | None = None` -- relative tolerance (e.g., 0.01 for ROIC)
       - At least one of absolute or relative must be non-None (add model_validator)

    2. `InputField(BaseModel)` -- frozen=True
       - `name: str` -- parameter name in the function signature
       - `type: str` -- type annotation as string (e.g., "float", "dict[str, Any]")
       - `akshare_field: str | None = None` -- AKShare raw field name mapping
       - `efinance_field: str | None = None` -- efinance raw field name mapping
       - `required: bool = True`
       - `description: str | None = None`

    3. `ReferenceValue(BaseModel)` -- frozen=True
       - `name: str` -- identifier for this reference case (e.g., "beneish_1999_table3_sample1")
       - `inputs: dict[str, float | str | bool]` -- named input values for the test
       - `expected_output: float | dict[str, float]` -- expected result
       - `source: str | None = None` -- citation (e.g., "Beneish 1999, Table 3")

    4. `Variant(BaseModel)` -- frozen=True
       - `function: str | None = None` -- override module path (e.g., "roic_service.calculate_nopat")
       - `params: list[InputField] | None = None` -- override parameter list
       - `tolerance: Tolerance | None = None` -- override tolerance
       - `display_name_suffix: str | None = None` -- e.g., "(Financial Sector)"

    5. `MetricDefinition(BaseModel)` -- frozen=True
       - `display_name: str` -- human-readable name (e.g., "Beneish M-Score")
       - `category: str` -- one of: risk, roic, valuation, yield, capex, policy, alpha
       - `function: str` -- module path + function name (e.g., "risk_service.calculate_beneish_m_score")
       - `params: list[InputField]` -- function parameter contracts
       - `returns: str` -- return type description
       - `tolerance: Tolerance` -- validation tolerance for this metric
       - `formula_ref: str | None = None` -- academic paper or textbook citation
       - `audit_trail_required: bool = False` -- whether audit trail is produced
       - `depends_on: list[str] = []` -- metric names this depends on (per D-02)
       - `priority: str = "P2"` -- P0, P1, or P2 validation priority
       - `variants: dict[str, Variant] = {}` -- sector variants keyed by name (per D-07)
       - `reference_values: list[ReferenceValue] = []` -- L1 test reference values from papers
       - `notes: str | None = None` -- free-form notes

    6. `MetricRegistry(BaseModel)` -- frozen=True
       - `metrics: dict[str, MetricDefinition]` -- flat dict keyed by metric name (per D-06)
       - Add model_validator(mode="after") that checks all `depends_on` entries reference existing metric names (cross-reference validation)
       - Add class method `from_yaml(yaml_string: str) -> MetricRegistry` that parses YAML string and returns validated registry
       - Add convenience methods:
         - `get(name: str, sector: str | None = None) -> MetricDefinition` -- returns metric, resolved to variant if sector given
         - `metrics_by_category(category: str) -> list[tuple[str, MetricDefinition]]`
         - `p0_metrics() -> list[tuple[str, MetricDefinition]]` -- filter priority=="P0"
         - `all_metrics() -> list[tuple[str, MetricDefinition]]` -- all entries as (name, def) tuples

    Follow project conventions: Python 3.12+ type syntax (`X | Y`, `list[X]`), Google-style docstrings, absolute imports (`from stockvaluefinder.validation.schema import ...`). Use `model_config = {"frozen": True}` on all models.
