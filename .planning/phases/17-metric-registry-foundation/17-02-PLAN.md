    **File: stockvaluefinder/validation/comparators.py**
    Create a frozen dataclass `ComparisonResult` and a pure function `compare_within_tolerance()`.

    ```python
    from dataclasses import dataclass
    from stockvaluefinder.validation.schema import Tolerance

    @dataclass(frozen=True)
    class ComparisonResult:
        """Result of comparing expected vs computed value against tolerance."""
        metric_name: str
        expected: float
        computed: float
        delta: float
        tolerance_applied: Tolerance
        passed: bool

    def compare_within_tolerance(
        expected: float,
        computed: float,
        tolerance: Tolerance,
    ) -> bool:
        """Check if computed value is within tolerance of expected value.

        If both absolute and relative tolerances are specified, the value
        passes if EITHER tolerance is satisfied (OR logic, not AND).

        Args:
            expected: Reference/expected value.
            computed: Actually computed value.
            tolerance: Tolerance specification.

        Returns:
            True if computed is within tolerance of expected.
        """
    ```

    Implementation logic for `compare_within_tolerance`:
    - delta = abs(computed - expected)
    - If tolerance.absolute is not None and delta <= tolerance.absolute: return True
    - If tolerance.relative is not None:
      - If expected == 0: fall back to absolute check (delta <= tolerance.relative) to avoid division by zero
      - Else: relative_delta = delta / abs(expected); if relative_delta <= tolerance.relative: return True
    - Otherwise return False

    **File: stockvaluefinder/validation/loader.py**
    Create the lru_cache singleton loader following the AppConfig.get_instance() pattern from config.py.

    ```python
    from functools import lru_cache
    from pathlib import Path

    import yaml
    from stockvaluefinder.validation.schema import MetricRegistry

    @lru_cache(maxsize=1)
    def load_metric_registry() -> MetricRegistry:
        """Load and validate the metric registry from YAML.

        Returns a cached MetricRegistry singleton. The YAML file is read
        from the package directory (stockvaluefinder/validation/metric_registry.yaml)
        and validated through the Pydantic schema on first call.

        Returns:
            Validated MetricRegistry instance.

        Raises:
            FileNotFoundError: If metric_registry.yaml is missing.
            ValidationError: If YAML content fails schema validation.
        """
        yaml_path = Path(__file__).parent / "metric_registry.yaml"
        yaml_content = yaml_path.read_text(encoding="utf-8")
        return MetricRegistry.from_yaml(yaml_content)
    ```
