c) `format_rich_table(result: ReconcileResult, verbose: bool = False) -> Table`:
   - Create a `rich.Table` with title: `"Reconcile: {ticker} {year}"`.
   - Columns (standard mode): METRIC, EXPECTED, COMPUTED, DELTA, TOLERANCE, STATUS.
   - In verbose mode, add columns: PRIORITY, CATEGORY, AUDIT_TRAIL.
   - For each comparison in `result.comparisons`:

     - Format delta to 6 decimal places.
     - Format tolerance as "abs=0.05" or "rel=1%" string.
     - Status: green "PASS" or red "FAIL" using `rich.Text`.
     - In verbose mode, add priority column (P0=red, P1=yellow, P2=default), category, and "Yes"/"No" for audit_trail_required.
   - Return the Table object.

d) `format_json_output(result: ReconcileResult) -> str`:
   - Build a JSON-serializable dict:
     ```python
     {
         "ticker": result.ticker,
         "year": result.year,
         "summary": result.summary,
         "skipped_metrics": result.skipped_metrics,
         "p0_all_pass": result.p0_all_pass,
         "comparisons": [
             {
                 "metric_name": c.metric_name,
                 "expected": c.expected,
                 "computed": c.computed,
                 "delta": c.delta,
                 "tolerance": {
                     "absolute": c.tolerance_applied.absolute,
                     "relative": c.tolerance_applied.relative,
                 },
                 "passed": c.passed,
             }
             for c in result.comparisons
         ],
     }
     ```
   - Return `json.dumps(output, indent=2)`.

e) `format_verbose_output(result: ReconcileResult) -> str`:
   - For each comparison, look up MetricDefinition and build a detailed string block:
     - Metric name, display name, category, priority.
     - Expected vs computed with delta.
     - Tolerance applied.
     - For metrics with `audit_trail_required: True`, note "Audit trail: available (see calculation logs)".
     - Add note about numerator/denominator breakdown being available in calculation function audit trail dicts.
   - This is supplementary text printed AFTER the table, not replacing it.

f) Main CLI command:
   ```python
   @app.command()
   def main(
       ticker: str = typer.Option(..., help="Stock ticker (e.g. 600519.SH)"),
       year: int = typer.Option(..., help="Fiscal year (e.g. 2023)"),
       metric: Optional[str] = typer.Option(None, "--metric", help="Limit to single metric"),
       verbose: bool = typer.Option(False, "--verbose", "-v", help="Show full audit trail breakdown"),
       json_output: bool = typer.Option(False, "--json", help="Output machine-parseable JSON"),
       live: bool = typer.Option(False, "--live", help="Fetch live data from AKShare (default: use frozen golden data)"),
   ) -> None:
   ```
   - If `live` is True:
     - Call `reconcile_live(ticker, year, metric)` using `asyncio.run()`.
     - This fetches real AKShare data via ExternalDataService.
   - Otherwise (default frozen mode):
     - Call `reconcile(ticker, year, metric)` from reconcile_core.
   - Try/except block around reconcile call:
     - On `FileNotFoundError`: print error via `Console(stderr=True)`, `raise typer.Exit(code=2)`.
     - On `KeyError`: print error via `Console(stderr=True)`, `raise typer.Exit(code=2)`.
     - On unexpected exceptions: print error, `raise typer.Exit(code=2)`.
   - If `json_output`:
     - Print `format_json_output(result)` via `Console()` (stdout).
     - Set exit code: 0 if `result.p0_all_pass`, else 1.
     - `raise typer.Exit(code=0 or 1)`.
   - Otherwise (human-readable mode):
     - Create `Console()`.
     - Print `format_rich_table(result, verbose=verbose)` via `console.print()`.
     - If verbose, also print `format_verbose_output(result)`.
     - Print summary line: "P0: {p0_passed}/{p0_total} passed ({p0_pass_rate}%) | Total: {passed}/{total} passed"
     - Print skipped metrics count if any.
     - Set exit code: 0 if `result.p0_all_pass`, else 1.
     - `raise typer.Exit(code=0 or 1)`.

g) Entry point for `python -m`:
   ```python
   if __name__ == "__main__":
       app()
   ```

3. Design notes:
   - Exit codes: 0 = success (all P0 pass), 1 = P0 failure, 2 = error (invalid input, missing data).
   - The `--verbose` flag adds PRIORITY/CATEGORY/AUDIT_TRAIL columns to the table AND prints detailed text blocks for each metric below the table.
   - Rich colors: PASS = green bold, FAIL = red bold, P0 = red, P1 = yellow.
   - JSON output goes to stdout (for piping), human-readable output goes to stdout too (Rich handles terminal detection).
   - Error messages go to stderr.
