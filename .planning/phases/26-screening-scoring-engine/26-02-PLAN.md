    - PE signal: If pe_ttm is not None and > 0, contribute `50.0 / max(pe_ttm, 1.0)` (lower PE = higher score). If pe_ttm is None or <= 0, contribute 0.0.

    - Dividend signal: contribute `snapshot.dividend_yield * 100.0` (higher yield = higher score)
    - Drawdown signal: contribute `(1.0 - snapshot.price_vs_52w_high) * 50.0` (deeper drawdown = higher score)
    - Return sum of all 4 signals, rounded to 2 decimal places.
    - Also populate `signals` dict on the result with the 4 individual signal values for transparency.

    Public function `screen_stock(snapshot: ScreeningSnapshot, config: MarketScannerConfig) -> ScreeningResult`:
    1. Apply hard exclusion rules in order:

       - turnover_ratio < config.min_turnover_ratio -> "Below minimum liquidity"
       - ocf_positive_years < config.min_ocf_positive_years -> "Persistently negative operating cash flow"

  <action>
    Create stockvaluefinder/stockvaluefinder/market_scanner/composite_scorer.py with 5 normalization functions and 1 scoring function. Follow the exact pattern from alpha_service.py (pure functions, no class, no I/O).

    Function 1 - normalize_safety_margin(margin: float | None) -> float:
    Map margin of safety to 0-100 using linear mapping.
    - None -> 0.0
    - NaN guard: margin != margin -> 0.0
    - Negative values -> 0.0
    - Linear: 0% -> 0, 30% -> 50, 60% -> 100. Formula: min(100.0, (margin / 0.60) * 100.0)
    - Round to 2 decimal places

    Function 2 - normalize_alpha_score(alpha: float | None) -> float:
    Pass-through with clamp (Alpha score is already 0-100 from alpha_service.py).
    - None -> 0.0
    - Clamp to [0.0, 100.0]
    - Round to 2 decimal places

    Function 3 - normalize_risk_penalty(risk_level: RiskLevel | None) -> float:
    Map risk level to inverted score (LOW risk = HIGH score).
    - None -> 0.0
    - LOW -> 100.0, MEDIUM -> 50.0, HIGH -> 0.0, CRITICAL -> 0.0
    - Dict mapping pattern (same as alpha_service.py normalize_capex_score)

    Function 4 - normalize_yield_gap(yield_gap: float | None) -> float:
    Map yield gap to 0-100 using linear clamp [-2%, +4%].
    - None -> 0.0
    - NaN guard
    - Clamp to [-0.02, 0.04]
    - Formula: ((clamped + 0.02) / 0.06) * 100.0
    - Round to 2 decimal places

    Function 5 - normalize_valuation_percentile(percentile_rank: float | None) -> float:
    Inverted mapping (lower percentile = cheaper = higher score).
    - None -> 50.0 (neutral default -- stock without percentile data gets middle score)
    - Clamp result to [0.0, 100.0]
    - Formula: 100.0 - percentile_rank
    - Round to 2 decimal places

    Function 6 - calculate_composite_score(
        margin_of_safety: float | None,
        alpha_score: float | None,
        risk_level: RiskLevel | None,
        yield_gap_value: float | None,
        valuation_percentile: float | None,
        config: MarketScannerConfig,
    ) -> CompositeScore:
    1. Normalize each component using the 5 normalize_* functions
    2. Build CompositeScoreComponents from normalized values
    3. Get weights from config.scoring_weights.weights_tuple
    4. Compute weighted sum: composite = sum(component * weight for each pair)
    5. Round composite to 2 decimal places
    6. Determine passed_threshold: composite >= config.min_composite_score
    7. Return CompositeScore(composite=composite, components=components, passed_threshold=passed_threshold)

    Follow alpha_service.py pattern exactly: NaN guards on numeric inputs, round(x, 2) on all outputs, ValueError on invalid weight count/sum.
