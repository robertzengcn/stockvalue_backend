    Public function signature:
    ```python
    def generate_reasons(
        composite_score: CompositeScore,
        valuation_result: ValuationResult | None = None,
        risk_score: RiskScore | None = None,
        yield_gap: YieldGap | None = None,
    ) -> CandidateReasons:
    ```

    Implementation structure:
    1. Initialize empty reasons: list[str] and risk_flags: list[str]
    2. Call domain-specific helper functions that each append to reasons/risk_flags:
       - _generate_valuation_reasons(valuation_result, reasons, risk_flags)
       - _generate_risk_reasons(risk_score, reasons, risk_flags)
       - _generate_yield_reasons(yield_gap, reasons, risk_flags)
       - _generate_composite_reasons(composite_score, reasons)
    3. Compliance enforcement: if len(risk_flags) == 0, append "Standard risk factors apply; review full analysis"
    4. Return CandidateReasons(reasons=reasons, risk_flags=risk_flags)

    Helper _generate_valuation_reasons(valuation_result, reasons, risk_flags):
    - If valuation_result is None: append risk_flag "DCF valuation not available"
    - If margin_of_safety >= 0.30: append reason "Safety margin {margin:.0%}, above 30% threshold"
    - If 0 < margin_of_safety < 0.30: append risk_flag "Safety margin {margin:.0%} below 30% threshold"
    - If margin_of_safety <= 0: append risk_flag "No safety margin ({margin:.0%}), intrinsic value below market price"

    Helper _generate_risk_reasons(risk_score, reasons, risk_flags):
    - If risk_score is None: append risk_flag "Risk analysis not available" and return
    - If risk_level in (HIGH, CRITICAL): append risk_flag "Risk level {risk_level.value}, M-Score={m_score:.2f}"
    - If risk_level == LOW: append reason "Low risk profile (M-Score={m_score:.2f})"
    - If risk_level == MEDIUM: append risk_flag "Moderate risk level (M-Score={m_score:.2f})"
    - If red_flags is non-empty: append risk_flag "{len(red_flags)} risk indicator(s): {'; '.join(red_flags[:3])}"
    - If profit_cash_divergence is True: append risk_flag "Profit-cash flow divergence detected"
    - If goodwill_excessive is True: append risk_flag "Excessive goodwill ratio"
    - If 存贷双高 is True: append risk_flag "High cash and high debt (cun-dai-shuang-gao)"
    - If f_score >= 7: append reason "Strong Piotroski F-Score ({f_score}/9), solid fundamentals"
    - If f_score <= 3: append risk_flag "Low Piotroski F-Score ({f_score}/9), fundamental weakness"

    Helper _generate_yield_reasons(yield_gap, reasons, risk_flags):
    - If yield_gap is None: append risk_flag "Dividend yield gap analysis not available" and return
    - If yield_gap > 0: append reason "Positive yield gap ({yield_gap:.2%}), dividend exceeds risk-free rate"
    - If yield_gap < 0: append risk_flag "Negative yield gap ({yield_gap:.2%}), dividend below risk-free rate"
    - If yield_gap == 0: append risk_flag "Yield gap at breakeven, dividend equals risk-free rate"

    Helper _generate_composite_reasons(composite_score, reasons):
    - If composite >= 70: append reason "Composite score {composite:.1f}, strong overall ranking"
    - If composite >= 50: append reason "Composite score {composite:.1f}, moderate overall ranking"

    Important constraints:
    - No LLM calls anywhere (SCR-06 explicit requirement)
    - All text uses deterministic templates with actual metric values
    - Use Python format strings with actual values, not placeholder text
    - The compliance rule (at least 1 risk flag) is enforced by the CandidateReasons model itself (min_length=1) AND by the fallback in generate_reasons
