  <behavior>
    Pure function calculate_valuation_percentile:
    - Returns float percentile (0-100) using scipy.stats.percentileofscore
    - Returns None when historical_values has fewer than 60 entries
    - Filters out non-positive values from both current_value and historical_values before computing
    - Handles NaN/inf in input by returning None
    - Rounds result to 2 decimal places

    BatchDataFetcher class:
    - __init__ accepts no arguments (stateless service)
    - fetch_market_snapshots(tickers: set[str], config: MarketScannerConfig) -> dict[str, ScreeningSnapshot]
    - Uses single AKShare stock_zh_a_spot_em() call for all A-shares
    - Maps 6-digit AKShare codes to project ticker format via _to_ticker_format helper
    - Filters DataFrame to requested tickers
    - Maps Chinese column names to ScreeningSnapshot fields
    - Detects ST status: "ST" in stock name (case-insensitive check on name field)
    - Detects suspension: turnover == 0 AND volume == 0
    - Sets has_price_data = True when latest price > 0
    - Uses _safe_float helper that returns None for NaN/inf/None values
    - Sets dividend_yield=0.0 (not available from bulk API, per RESEARCH Pitfall 2)
    - Sets price_vs_52w_high=1.0 (neutral default, per RESEARCH Pitfall 6)
    - Sets ocf_positive_years=0 (filled later, per RESEARCH Pitfall 5)
    - Per-ticker try/except: individual failures logged, not raised
    - Returns dict mapping ticker -> ScreeningSnapshot for successful fetches only
    - Exposes errors dict via self._errors attribute
    - Uses asyncio.to_thread for the synchronous AKShare call
  </behavior>
