    QualityReviewResult model:
    - passed: bool
    - failure_reasons: list[str] (empty when passed=True)
    - checks_detail: dict[str, bool] mapping check name to pass/fail for audit trail

    review_stock_quality function:
    - Check 1 (ROIC-WACC spread): If roic_wacc_spread is not None and <= 0, fail with "ROIC-WACC spread {value:.2%} is non-positive"
    - Check 2 (M-Score): If risk_score is not None and risk_score.m_score >= -1.78, fail with "M-Score {value:.2f} above manipulation threshold -1.78"
    - Check 3 (Cash flow divergence): If risk_score is not None and risk_score.profit_cash_divergence is True, fail with "Profit-cash flow divergence detected"
    - Check 4 (Risk level gate): If risk_score is not None and risk_score.risk_level in (RiskLevel.HIGH, RiskLevel.CRITICAL), fail with "Risk level {value} exceeds acceptable threshold"
    - Check 5 (Leverage): If risk_score is not None and risk_score.存贷双高 is True, fail with "High cash and high debt anomaly (cun-dai-shuang-gao)"
    - Check 6 (Dividend sustainability): If yield_gap is not None and yield_gap.yield_gap < -0.02, fail with "Negative yield gap ({value:.2%}), dividend sustainability concern"
    - Graceful degradation: If risk_score is None, checks 2-5 are skipped (not failed)
    - If yield_gap is None, check 6 is skipped
    - If roic_wacc_spread is None, check 1 is skipped
    - All checks that are skipped are recorded in checks_detail with value True (not failing = passing by absence)
  </behavior>

       - Check 2 (M-Score): if risk_score is not None: checks["m_score"] = risk_score.m_score < -1.78; if risk_score.m_score >= -1.78: append failure
       - Check 3 (Cash flow divergence): if risk_score is not None: checks["cash_flow_divergence"] = not risk_score.profit_cash_divergence; if risk_score.profit_cash_divergence: append failure
       - Check 4 (Risk level): if risk_score is not None: checks["risk_level"] = risk_score.risk_level not in (RiskLevel.HIGH, RiskLevel.CRITICAL); if risk_level is HIGH or CRITICAL: append failure
       - Check 5 (Leverage): if risk_score is not None: checks["leverage"] = not risk_score.存贷双高; if 存贷双高: append failure
       - Check 6 (Dividend sustainability): if yield_gap is not None: checks["dividend_sustainability"] = yield_gap.yield_gap >= -0.02; if yield_gap.yield_gap < -0.02: append failure

       - Return QualityReviewResult(passed=len(failures) == 0, failure_reasons=failures, checks_detail=checks)
