  <behavior>
    ScanOrchestrator class:
    - __init__(self, config: MarketScannerConfig, data_service: ExternalDataService, run_repo: MarketScanRunRepository, candidate_repo: MarketScanCandidateRepository, constituent_repo: IndexConstituentRepository, batch_fetcher: BatchDataFetcher)
    - run_scan(self, index_code: str, scan_type: ScanType) -> UUID:
      1. Create scan run via run_repo.create_run() with status=pending
      2. Transition to running via run_repo.mark_running()
      3. Get active constituents for index_code from constituent_repo
      4. Extract ticker set from constituents
      5. Fetch market snapshots via batch_fetcher.fetch_market_snapshots()
      6. Run screen_stocks() on all snapshots
      7. Run rank_screened_stocks() with top_n from config (daily_top_n or weekly_top_n)
      8. For each top-N stock, run _analyze_single_stock() with failure isolation
      9. Collect results: passed candidates (passed quality review + passed composite threshold)
      10. Persist candidates via candidate_repo.create()
      11. If any errors occurred: mark_partial_failed with error_summary; else mark_completed
      12. Return run_id

    _analyze_single_stock(self, ticker: str, snapshot: ScreeningSnapshot) -> StockAnalysisResult | None:
      1. Fetch financial data via data_service.get_financial_report(ticker)
      2. Fetch previous year data via data_service.get_financial_report(ticker, year-1)
      3. Fetch price via data_service.get_current_price(ticker)
      4. Fetch FCF via data_service.get_free_cash_flow(ticker)
      5. Fetch shares via data_service.get_shares_outstanding(ticker)
      6. Run analyze_dcf_valuation() with default DCFParams
      7. Check safety margin >= config.min_margin_of_safety; if not, return StockAnalysisResult with passed=False
      8. Run analyze_financial_risk() with current and previous reports
      9. Run review_stock_quality() with valuation result, risk score, and yield gap
      10. If quality review fails, return StockAnalysisResult with passed=False
      11. Run calculate_composite_score() with all metrics
      12. Run generate_reasons() with all analysis outputs
      13. Return StockAnalysisResult with all data for candidate persistence
      14. On ANY exception: log warning, record error, return None (failure isolation)

    StockAnalysisResult dataclass:
    - ticker: str
    - passed: bool
    - composite_score: CompositeScore | None = None
    - reasons: CandidateReasons | None = None
    - valuation_result: ValuationResult | None = None
    - risk_score: RiskScore | None = None
    - snapshot: ScreeningSnapshot | None = None
  </behavior>
