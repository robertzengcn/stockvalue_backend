Create `stockvaluefinder/stockvaluefinder/market_scanner/worker.py` with the following structure:

1. **Module docstring** explaining this is the arq worker for scheduled market scans.

2. **Helper function `_build_orchestrator`**: Takes `AsyncSession` and `MarketScannerConfig`, returns a `ScanOrchestrator` instance. Instantiates all required dependencies:
   - `ExternalDataService` (from `stockvaluefinder.external.data_service`)
   - `MarketScanRunRepository(session)`
   - `MarketScanCandidateRepository(session)`
   - `IndexConstituentRepository(session)`
   - `BatchDataFetcher()`
   - Calls `await data_service.initialize()` before returning orchestrator.

3. **Job function `run_market_scan`**: Signature `async def run_market_scan(ctx: dict[str, Any], index_codes: list[str] | None = None, scan_type: str = "daily", top_n: int | None = None) -> dict[str, str]`.
   - Uses `async_session_maker` (from `stockvaluefinder.db.base`) via `async with async_session_maker() as session:`.
   - Creates `MarketScannerConfig()` (default config). If `top_n` is provided, use `dataclasses.replace` to create a new config with the override on `daily_top_n` or `weekly_top_n` depending on scan_type.
   - Converts `scan_type` string to `ScanType` enum.
   - Uses `index_codes` from parameter if provided, otherwise falls back to `config.index_codes`.
   - For each `index_code`:
     - Creates `MarketScanRunRepository(session)` and calls `get_latest_run(index_code)`.
     - If latest run exists and status is "running" or "pending", log a warning and skip (concurrent scan prevention, per PITFALLS Pitfall 5).
     - Otherwise, builds orchestrator via `_build_orchestrator(session, config)`, calls `await orchestrator.run_scan(index_code, scan_type_enum)`, commits session.
     - Logs completion with run_id.
   - Returns `{"status": "completed"}`.
   - Any exception caught at outer level, logged, returns `{"status": "failed", "error": str(e)}`.

4. **Cron function `daily_light_scan`**: Signature `async def daily_light_scan(ctx: dict[str, Any]) -> dict[str, str]`.
   - Delegates to `run_market_scan(ctx, scan_type="daily")`.

5. **Cron function `weekly_deep_scan`**: Signature `async def weekly_deep_scan(ctx: dict[str, Any]) -> dict[str, str]`.
   - Delegates to `run_market_scan(ctx, scan_type="weekly")`.
