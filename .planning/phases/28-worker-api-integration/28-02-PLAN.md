**Part A: Add repository methods to `market_scan_repo.py`**

Add these methods to `MarketScanRunRepository`:

1. `async def list_runs_paginated(self, page: int = 1, limit: int = 20, status: str | None = None, scan_type: str | None = None) -> tuple[list[MarketScanRunDB], int]`:
   - Build a base `select(MarketScanRunDB)` query.
   - If `status` is provided, add `.where(MarketScanRunDB.status == status)`.
   - If `scan_type` is provided, add `.where(MarketScanRunDB.scan_type == scan_type)`.
   - Count query: `select(func.count()).select_from(MarketScanRunDB)` with same filters.
   - Data query: `.order_by(MarketScanRunDB.created_at.desc()).offset((page - 1) * limit).limit(limit)`.
   - Execute both queries, return `(list(result.scalars().all()), total)`.

2. `async def get_candidate_by_id(self, candidate_id: UUID) -> MarketScanCandidateDB | None`:
   - `select(MarketScanCandidateDB).where(MarketScanCandidateDB.candidate_id == candidate_id)`.
   - Return `result.scalar_one_or_none()`.

Add this method to `MarketScanCandidateRepository`:

3. `async def list_candidates_paginated(self, run_id: UUID, page: int = 1, limit: int = 20, index_code: str | None = None, sort_by: str = "composite_score", sort_order: str = "desc") -> tuple[list[MarketScanCandidateDB], int]`:
   - Base query: `select(MarketScanCandidateDB).where(MarketScanCandidateDB.run_id == run_id, MarketScanCandidateDB.passed.is_(True))`.
   - If `index_code` provided, add `.where(MarketScanCandidateDB.index_code == index_code)`.
   - Count query with same filters.
   - Sorting: Use a sort_map dict:
     - `"composite_score"` -> `MarketScanCandidateDB.composite_score`
     - `"safety_margin"` -> use `text("CAST(screening_snapshot->>'margin_of_safety' AS FLOAT)")` for JSONB extraction per RESEARCH.md Pitfall 4.
     - `"created_at"` -> `MarketScanCandidateDB.created_at`
   - Default sort: `"composite_score"`.
   - If `sort_order == "desc"`, apply `.desc()`, else `.asc()`.
   - Offset/limit pagination as above.
   - Return `(candidates_list, total)`.

```python
class ScanRunResponse(BaseModel):
    """API response model for a scan run summary."""
    model_config = {"frozen": True}
    run_id: UUID
    index_codes: list[str]
    scan_type: str
    status: str
    rules_version: str
    total_count: int
    screened_count: int
    candidate_count: int
    started_at: datetime | None = None
    completed_at: datetime | None = None
    created_at: datetime

class ScanRunListResponse(BaseModel):
    """Paginated list of scan run summaries."""
    model_config = {"frozen": True}
    runs: list[ScanRunResponse]
    pagination: PaginationMeta

class CandidateListItemResponse(BaseModel):
    """Summary model for candidate in a list view."""
    model_config = {"frozen": True}
    candidate_id: UUID
    run_id: UUID
    ticker: str
    index_code: str
    composite_score: float
    safety_margin: float | None = None
    intrinsic_value: float | None = None
    risk_level: str | None = None
    created_at: datetime

class CandidateListResponse(BaseModel):
    """Paginated list of candidate summaries."""
    model_config = {"frozen": True}
    candidates: list[CandidateListItemResponse]
    pagination: PaginationMeta

class CandidateDetailResponse(BaseModel):
    """Full detail model for a single candidate."""
    model_config = {"frozen": True}
    candidate_id: UUID
    run_id: UUID
    ticker: str
    index_code: str
    composite_score: float
    screening_snapshot: dict[str, Any]
    created_at: datetime
```
