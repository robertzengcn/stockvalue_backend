<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| AKShare API -> AKShareClient | External HTTP data from East Money; Chinese field names, 6-digit codes |
| Redis Cache -> DataService | Cached bulk responses may be stale; TTL=24h limits freshness |
| DataService -> Downstream (Phase 30) | Normalized Pydantic models cross this boundary |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-29-04 | Spoofing | AKShare API response | mitigate | Explicit field mapping dict; unexpected fields silently ignored |
| T-29-05 | Tampering | Redis cache poisoning | accept | Cache keys use version prefix (v1:); TTL=24h limits damage window; financial data is public |
| T-29-06 | Denial of Service | East Money API rate limiting | mitigate | Built-in rate limiting in _run_sync (0.5s between requests); retry with exponential backoff (5 attempts) |
| T-29-07 | Tampering | Ticker injection via non-numeric codes | mitigate | normalize_a_share_ticker validates format+prefix, returns None for invalid; filter uses 6-digit code match |
| T-29-08 | Information Disclosure | Error message leakage | mitigate | AKShare errors wrapped in ExternalAPIError with sanitized message; no raw exception propagation |
| T-29-SC | Tampering | pip installs | accept | No new packages installed in this phase |
</threat_model>
