       - Does NOT inherit from BaseRepository (like RiskScoreRepository, uses direct session pattern for custom upsert logic).
       - __init__(self, session: AsyncSession) -- stores self._session = session, self.model = EquityPledgeSnapshotDB
       - async def upsert_by_ticker_date_source(self, ticker: str, latest_date: date, source: str, data: dict) -> EquityPledgeSnapshotDB:
         - Select existing by (ticker, latest_date, source) match
         - If found: setattr each field from data dict, flush, refresh, return
         - If not found: create EquityPledgeSnapshotDB(**data), add, flush, refresh, return
         - This implements DB-05 upsert semantics

       PledgeDetailRepository:
       - __init__(self, session: AsyncSession) -- stores self._session = session, self.model = EquityPledgeDetailDB
       - async def replace_details_for_ticker(self, ticker: str, details_data: list[dict]) -> list[EquityPledgeDetailDB]:
         - Delete all existing rows where EquityPledgeDetailDB.ticker == ticker (using delete() statement)
         - For each item in details_data: create EquityPledgeDetailDB(**item), add to session
         - Flush, return created list
         - This implements DB-05 replace-all semantics (per RESEARCH.md: AKShare details lack stable unique IDs)
       - async def get_by_ticker(self, ticker: str, limit: int = 100) -> list[EquityPledgeDetailDB]:
