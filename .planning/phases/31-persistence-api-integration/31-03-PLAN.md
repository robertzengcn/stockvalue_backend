       Change `PromptBuilder = Callable[[str, dict[str, Any]], tuple[str, str]]`
       to `PromptBuilder = Callable[..., tuple[str, str]]` (use ... to allow optional params)

       ```
       def build_risk_prompt(
           ticker: str,
           result_data: dict[str, Any],
           pledge_data: dict[str, Any] | None = None,
       ) -> tuple[str, str]:
       ```
       The pledge_data parameter receives pledge_risk_result.model_dump() from risk_routes.py.

    3. Build the pledge section conditionally (insert between existing focus point 6 and the closing):

       ```
       pledge_section = ""

       if pledge_data is not None:
           data_quality = pledge_data.get("data_quality", {})
           freshness = data_quality.get("freshness", "UNAVAILABLE")
           supported = pledge_data.get("supported", True)

           if not supported:
               # NARR-05 (HK stocks): simple note, no risk assessment
               pledge_section = """
       7. 股权质押：该股票为港股，港股不支持质押数据，无需分析质押风险。
       """
           elif freshness == "UNAVAILABLE":
               # NARR-03: explicitly state unavailable, forbid implying low risk
               pledge_section = """
       7. 股权质押风险：质押数据不可得。重要约束：你只能说明"质押数据不可得"，不得暗示质押风险较低或较高，不得对质押风险做出任何推断。
       """
           else:
               # NARR-01: full pledge risk paragraph with structured data
               breakdown = pledge_data.get("risk_level_breakdown", {})
               company_risk = pledge_data.get("company_risk", {})
               holder_risk = pledge_data.get("holder_risk", {})
               closeout_risk = pledge_data.get("closeout_risk", {})

               closeout_note = ""
               safety_margin = closeout_risk.get("safety_margin")
               if safety_margin is not None:
                   closeout_note = f"   - 平仓线安全距离: {safety_margin:.1f}%\n"
               # NARR-04: when safety_margin is null, omit closeout distance entirely

               pledge_section = f"""
       7. 股权质押风险分析:
          - 最终风险等级: {breakdown.get('final_risk_level', 'N/A')}
          - 公司质押比例: {company_risk.get('company_pledge_ratio', 'N/A')}
          - 控股股东质押比例: {holder_risk.get('pledged_to_holding_ratio', 'N/A')}
       {closeout_note}
          重要约束（必须严格遵守）：
          - 你只能使用以上结构化字段中的质押数值，不得编造任何质押相关数字（NARR-02）
          - 如果平仓线安全距离未提供，请勿提及平仓线距离（NARR-04）
          - 质押相关分析必须完全基于上述数据，不得引入数据中不存在的数字或比例
       """
       ```

    4. Insert pledge_section into the user_prompt. After the existing focus point 6 ("综合风险等级的投资含义"), append the pledge_section. The existing format uses f-string with numbered focus points. Change the existing user_prompt to end with `{pledge_section}` appended after point 6.

    5. IMPORTANT: Existing callers of build_risk_prompt that pass only (ticker, result_data) must continue to work unchanged since pledge_data defaults to None. The pledge_section will be empty string when pledge_data is None, preserving backward compatibility.

       ```
       result_data_for_narrative = risk_score.model_dump()

           narrative_svc=narrative_svc,
       )
       ```
       Since generate_and_serialize_narrative calls prompt_builder(ticker, result_data), we need to adapt with a lambda that captures pledge_data. Alternatively, pass pledge_data through result_data dict and have build_risk_prompt extract it -- but using a lambda is cleaner and keeps the separation clear.
